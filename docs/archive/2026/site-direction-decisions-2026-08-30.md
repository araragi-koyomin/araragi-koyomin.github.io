# 网站方向与公开身份决策记录

## 背景

首轮接手发现本地正在进行中文化和个人笔记迁移，但公开内容、语言、About 页面、作者
身份、站点标题和部署触发方式尚未形成明确基线。这些选择会直接影响文章清理、页面
文案、元数据和发布工作，因此在正式开发前由用户确认。

## 已确认决定

### 1. 公开内容

只公开用户的个人文章和笔记。AstroPaper 教程、示例和 release 文章不再参与公开博客
展示；该决定不要求替换 AstroPaper 框架。

影响：后续需要检查首页、文章列表、标签、归档、搜索、RSS、图片和文章链接，确保
模板内容不会通过其他入口继续出现。

### 2. 语言

网站界面全面使用简体中文。英文技术术语只在确有必要时保留，并按项目沟通规则提供
中文解释。

影响：导航、搜索、分页、日期、分享、返回按钮、404、About、辅助文本、HTML 语言
属性和元数据都需要统一。

### 3. About 页面

保留并重写 About 页面。当前只确认页面用途，尚未确认具体自我介绍文案，因此不得
自行编造个人经历或联系方式。

### 4. 作者身份

显示名称统一为“往目琛”，profile 指向
`https://github.com/araragi-koyomin`。

影响：站点配置、文章默认作者、版权信息、结构化数据、社交链接和文章编辑链接需要
使用同一身份基线。

### 5. 站点标题

正式站点标题使用“私立直江津高校”，首页栏目标题使用“图书馆”。

影响：页面标题、Open Graph 图片和描述可以保留这一主题，但文案和页面结构不应让
访问者误认为它是现实学校的官方网站。

### 6. 部署方式

保留 GitHub Actions 构建并发布到 `gh-pages` 的架构，但改为用户手动触发；推送
`main` 不再自动发布。

影响：后续需要修改工作流触发条件、更新 README，并继续遵守“实际部署必须获得当次
明确授权”的安全边界。
